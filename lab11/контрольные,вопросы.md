13. Что такое компонент?
Компонент — это независимый и переиспользуемый строительный блок пользовательского интерфейса (UI) в React.

Он концептуально похож на JavaScript-функции: принимает произвольные входные данные (называемые props) и возвращает React-элементы, описывающие, что должно появиться на экране. Компоненты могут быть функциональными (в виде обычных или стрелочных функций) или классовыми.

14. Для чего нужны props?
Props (сокращение от properties — свойства) нужны для передачи данных от родительского компонента дочернему.

Они позволяют делать компоненты динамическими и универсальными, передавая в них текст, изображения, функции обратного вызова и другие данные извне.

15. Почему props считаются входными данными?
Пропсы считаются входными данными, потому что они «только для чтения» (read-only) для дочернего компонента.

Дочерний компонент никогда не должен пытаться изменять переданные ему пропсы. Согласно концепции React, компоненты должны вести себя как чистые функции относительно своих пропсов (один и тот же вход всегда дает один и тот же результат).

16. Что такое state?
State (состояние) — это встроенный объект в React-компоненте, который содержит данные, способные изменяться с течением времени в результате действий пользователя, сетевых запросов или таймеров.

В отличие от пропсов, которые передаются извне родительским компонентом, состояние является внутренним и полностью контролируется самим компонентом.

17. Как работает useState?
useState — это React-хук, который позволяет добавлять локальное состояние в функциональные компоненты.

Он принимает один аргумент — начальное значение состояния — и возвращает массив из двух элементов:

Текущее значение состояния.

Функцию-сеттер для его обновления (например, const [count, setCount] = useState(0)).

При вызове функции-сеттера React планирует перерисовку компонента с новым значением.

18. Когда происходит повторный рендер?
Повторный рендер (re-render) компонента происходит в следующих основных случаях:

Когда изменяется состояние компонента (вызывается функция обновления из useState или useReducer).

Когда изменяются пропсы, передаваемые компоненту из родительского компонента.

Когда перерисовывается родительский компонент (по умолчанию дочерние компоненты тоже рендерятся заново, если не оптимизированы с помощью React.memo).

19. Как обработать click в React?
Клик обрабатывается с помощью специального атрибута события onClick, которому передается функция-обработчик (callback).

Пример:<button onClick={() => console.log('Клик!')}>Нажми на меня</button>
20. Почему нельзя изменять state прямым присваиванием?
Прямое изменение состояния (например, state.count = 5) не вызывает повторный рендер компонента, поэтому пользователь не увидит изменений на экране.

Кроме того, это нарушает принцип иммутабельности (неизменяемости) данных в React, что может ломать логику сравнения изменений (Virtual DOM, оптимизации вроде useEffect или shouldComponentUpdate), приводя к трудноуловимым багам.

21. Чем локальное состояние отличается от props?
Источник: Props передаются компоненту «снаружи» его родителями; state создается и управляется «изнутри» самого компонента.

Изменяемость: Props неизменяемы (read-only) для принимающего компонента; state изменяем с помощью специальной функции-сеттера.

22. Как передать обработчик из родителя ребенку?
Обработчик (функция) передается точно так же, как и любые другие данные — через пропсы.

Пример:// В родителе:
<ChildComponent onClickHandler={handleClick} />

// В ребенке:
<button onClick={props.onClickHandler}>Клик</button>
23. Что такое управляемое поле ввода?
Управляемое поле ввода (Controlled Component) — это элемент формы (например, <input>, <textarea>, <select>), значение которого полностью контролируется состоянием React-компонента.

Значение поля привязано к state, а каждое изменение (onChange) обновляет этот state, что гарантирует синхронизацию интерфейса и данных.

24. Как проверить, что два экземпляра компонента независимы?
Можно создать два экземпляра одного компонента на странице (например, два счетчика) и изменить состояние в одном из них.

Если при изменении состояния первого компонента значение или поведение второго осталось прежним, значит, экземпляры полностью независимы (у каждого свое изолированное локальное состояние).
